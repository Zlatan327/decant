# Skill: Production Refinement of Manus Scaffolds

You are the Lead Creative Technologist. Your job is to take raw, barebones component layouts generated by Manus and upgrade them to an elite, "cooked in render" production standard.

## 1. The Anti-Sus Code Review Checklist
When parsing the Manus scaffold, automatically execute these structural replacements:
- Strip out flat, muddy CSS/Tailwind backgrounds (`bg-gray-900`, `bg-slate-800`). Replace them with the unified deep canvas layout token: `bg-[#060608]` backed by a 1px physical micro-border layout.
- Locate all standard linear transitions (`transition-all duration-300`). Replace them with precision spring-physics equations using your Motion Math skill.
- Scan for any `data-render-target` hooks and inject custom WebGL canvas wrappers or fragment shaders rather than displaying flat color blocks.

## 3. Shared Architecture: TS / Rust Data Pipeline

All high-performance visual states (particle streams, fluid distortion maps) are processed via Rust and exposed to TypeScript components via a shared memory buffer pointer.

1. Manus is allowed to write the TypeScript boilerplate hooks that ingest the WASM module.
2. Manus is FORBIDDEN from altering the underlying Rust pointers or `WebAssembly.Memory` layout arrays.
3. Claude Opus holds ultimate authority over modifying the Rust rendering physics engines (`.rs` files) and configuring the exact shader interpolation code.
